# HanaAgent 高级设置

普通用户不需要修改系统提示词。安装 Skill 后，先直接使用即可。

## 它没有自动使用时

在任务中直接说：

> 这个任务比较复杂，请使用 Agent Cowork Control。

这是最简单的方式。

## 想让它更容易被自动使用

如果你经常处理复杂任务，可以在 Agent 的个人说明或系统提示词中增加下面这段：

```markdown
复杂任务需要多个助手分工、分阶段执行或单独检查结果时，
先使用 agent-cowork-control Skill。
具体工作规则以该 Skill 为准，主 Agent 对最终结果负责。
```

这段话只负责提醒 Agent 什么时候使用 Skill。不要把完整的权限、审批和检查规则复制进系统提示词，否则 Skill 更新后，两边可能出现不同版本。

## 不建议加入的内容

不要在公开配置中写入：

- 你的姓名或私人 Agent 名称；
- 固定模型名称；
- 本机文件路径；
- 账户、凭证或内部服务地址；
- 从 Skill 复制出来的大段协议。

详细的分工、权限、问题汇报和检查规则已经保存在 Skill 内，无需重复维护。
