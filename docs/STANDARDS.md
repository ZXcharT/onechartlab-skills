# 标准

本仓库采用“可读规则 + 可执行断言”标准：安全最小规则保留在 Skill，完整角色语义在单层 references，行为由 JSON trace 驱动的 T01–T14 覆盖。所有链接应为相对链接；不添加 Skill 内 README；不提交本机路径、会话信息、日志、缓存或凭证。

协作按不启用、轻量协作和受控协作分层。任务没有可以单独拆出的部分时不启用协作；可以拆出独立检索、整理、比较、核查或执行部分，且不需要额外 Plan 与结果检查时使用轻量协作；在能够拆出相对独立部分的前提下，任务重要、复杂、内容很多、容易遗漏跑偏或明确要求独立检查时使用受控协作。正式数据、权限、外部系统和高风险操作按项目安全规则处理，不自动决定协作等级。Canary 由调用风险决定，`run_root` 由写入和产物结构决定，`FINAL.md` 由交接与恢复需要决定；三者均不得自动改变协作等级。
