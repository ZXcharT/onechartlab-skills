# 执行型子代理协议

执行者只在已批准边界内产出或变更，不重新定义目标、架构和范围。权限、审批和安全最小规则见主 Skill；异常时加载 [沟通协议](communication-protocol.md)。

## 数据执行：两阶段同线程

### 1. Canary

主代理创建唯一 write 数据执行者，首条任务只调用计划中的精确结构化/MCP 工具一次，写明工具全名、最小参数、成功判据和禁止动作。

- `CANARY_OK`：主代理用同一 `threadId` 追加生产任务。
- `CANARY_BLOCKED`：停止受影响分支，按 `COMMUNICATION_EVENT` 回传；主代理先报告影响与恢复方案。

失败后不得自动换源。换源、扩权、降级或扩大范围必须请求决定或重新审批。

### 2. 生产

任务包限定允许工具、数据源顺序、唯一目录和允许文件。执行者只负责查询、清洗、标准化、缺失标记、来源记录与证据落盘，不作最终判断。

证据包至少包含：原始响应、结构化数据、来源账本、字段口径、缺失/冲突清单、可重跑脚本。其他研究者读取同一底稿，不重复查询。完成后立即关闭实例。

## write 硬停止条件

命中以下任一项，停止受影响分支，返回状态、证据、已有文件、影响、恢复建议、能否安全继续和待决定事项：

- Canary 失败，工具不可见，权限或认证不符
- 需换源或以网页/浏览器替代计划中的结构化接口
- 需新增或删除计划外文件，新增或升级依赖
- 需改变公共接口、数据结构、字段或研究口径
- 需修改配置、安全、权限、凭证、环境或目录外状态
- 需跨入计划外模块或扩大范围
- 需删除或覆盖重要数据，或对外发送
- 原 Plan 基于错误事实或不可实现假设
- `run_root` 未获用户授权、运行目录归属不明或有其他会话写入

局部恢复遵守沟通协议：最多一次低成本可逆尝试；整体失败、第二次同错、改派/抢救日志或可信度变化时立即回传，不得事后补报。

## 自检

1. 开始前核对任务包、文件现状和工具。
2. 不顺手重构无关部分，不重复已分配任务。
3. 每个可独立验证阶段运行检查；文件任务核对真实文件。
4. 清洗、合并、校正和生成必须进入可复现链，不能依赖未保存的一次性命令。
5. 从原始输入重跑关键链路，确认不覆盖后续修订。
6. 失败先诊断并保留证据，不原样重复操作。

## 精简输出

```markdown
# 执行结果
## 完成状态
RUNNING / RECOVERING / BLOCKED / FAILED / NEEDS_REVISION / NEEDS_USER_DECISION / COMPLETED
## 产出路径
## 关键结果
## 验证证据
## 偏差、冲突与未完成项
## 沟通事件
关键异常附 COMMUNICATION_EVENT；无则写“无”
```

局部问题最多接受一次带证据返修；再次失败由主代理接管并报告。
