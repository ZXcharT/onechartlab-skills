# 标准

本仓库采用“可读规则 + 可执行断言”标准：安全最小规则保留在 Skill，完整角色语义在单层 references，行为由 JSON trace 驱动的 T01–T14 覆盖。所有链接应为相对链接；不添加 Skill 内 README；不提交本机路径、会话信息、日志、缓存或凭证。

协作强度按直接执行、轻量协作和受控协作分层；只有任务存在明确分工收益时才启用协作，命中关键决策、高风险、多个写入责任域、正式数据、持久交接、权限或外部系统等条件时升级为受控协作。轻量协作遇到风险调用、隔离或正式交接需求时先升级；受控协作中的批量、写入、结构或权限不确定、高成本或高影响结构化调用先 Canary，失败即 `BLOCKED`，不得静默换来源或扩权。普通单一写入者直接使用授权目标目录；多个写入责任域、批量或正式数据、可重跑证据及中间产物隔离才使用授权 `run_root`。`FINAL.md` 仅用于持久交接、跨会话恢复、多产物汇总或用户明确要求的正式证据包。
