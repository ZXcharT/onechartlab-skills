# T01–T14 行为契约

本契约列出公开版不可退化的行为。仓库源码中的标准库测试会为每条规则运行至少一个允许场景和一个阻断/替代场景；单独安装 Skill 时，本文件仍提供完整规则索引。

| ID | 行为 | 必须通过 | 必须阻断或改道 |
|---|---|---|---|
| T01 | Plan 分层 | 单步明确小范围任务可直接执行；普通多步骤和轻量协作以简短“步骤 → 验证”计划获 approver 确认后执行；受控协作以六段 Plan 同时通过 approver 确认和独立 read-only 新 thread 审查后执行 | 直接执行条件不成立、轻量计划未确认，或受控 Plan 缺少任一确认、身份、权限或独立 thread 时等待 |
| T02 | 身份路由与 thread | 用户指定优先；否则选择合适专业 Agent；没有合适角色时使用当前角色创建新子 thread | 用户指定不可用、跨角色复用 thread、静默替换或未批准模型覆盖 |
| T03 | 最小权限 | 研究/验证/审查 read，唯一写者 write | read 角色获得 write |
| T04 | Canary 按风险触发 | 低成本、只读、结构已知且结果可直接验证的单次调用可直接执行；批量、写入、结构或权限不确定、高成本或高影响调用在 Canary 成功且同 thread 后生产 | 直接执行条件不完整，或应 Canary 的调用未探测、失败、换 thread、换工具范围或换源时阻断 |
| T05 | QUERY_BACKLOG | 已有责任域的补充查询进入 backlog | 重复派人拉同一责任域 |
| T06 | 写入路径分层 | 只读任务直接通过；普通交付在授权目标目录由单一写入者完成；多写入责任域、批量或正式数据、独立可重跑证据及需隔离中间产物使用授权 run_root 和互不重叠目录 | 普通目标未授权、写入者或归属冲突，或应隔离任务缺少授权 run_root、目录重叠或每目录多写者时阻断 |
| T07 | 完成分层 | 直接任务和轻量协作在成功标准满足且主代理验收后交付；受控协作在结果审核完成并由主代理裁决为 ACCEPTED 后交付；命中 FINAL 门槛时还需完整且与实际产物和验证一致 | 成功标准未满足、受控结果审核未完成，或应有 FINAL 但缺失、不完整或失真时保持最终回复阻断 |
| T08 | 状态汇报 | STATUS_REPORT 后继续安全无依赖工作 | 将状态报告误作审批请求 |
| T09 | 失败穿透 | 后台失败向用户可见层报告 | 只写内部日志或报告前继续生产 |
| T10 | 受限恢复 | 首次局部可逆故障恢复一次 | 第二次同错、换源、扩权或降级 |
| T11 | NEEDS_REVISION | 主代理接管返修和确定性检查 | 再派独立审核或直接接受 |
| T12 | 重新审批 | 实质变化触发 REAPPROVAL_REQUIRED | 以普通状态报告替代批准 |
| T13 | 沟通协议加载 | 事件前加载唯一协议源 | 未加载即处理事件 |
| T14 | 加载失败硬阻断 | 协议缺失时保持 HARD_BLOCK | 依赖摘要恢复、返修、生产或交付 |

这些测试验证公开策略模型和 trace 合约，不代表宿主运行时提供系统级强制安全。宿主若有更强的权限或状态机机制，可以在不削弱本契约的前提下加固。
