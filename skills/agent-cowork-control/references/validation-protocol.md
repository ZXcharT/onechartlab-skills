# 验证型子代理协议

验证者独立检查事实、规则和验收标准；不修改被验证对象，不取得最终批准权。权限、审批和安全最小规则见主 Skill；异常时加载 [沟通协议](communication-protocol.md)。

## 启用条件

数据/事实密集、多对象比较、重要判断、复杂产出、安全权限或执行者不确定性时按需启用。简单且可用确定性工具验证的任务不强制委派。

## 阶段审核资格

审核次数按已批准 Plan 阶段计算，不按聊天窗口计算。同一阶段最多派出一次独立审核，审核结束后即记为 `AUDIT_DONE`，无论结果为通过、发现问题或阻塞，都不得再次派审核助手或进行增量复核。返修、文件变化、补充证据、发现新问题以及拆分或重命名阶段均不刷新审核资格；审核后的返修、确定性检查与最终验收由主代理负责。只有原 Plan 已定义的下一阶段、approver 批准实质范围变化后形成的新阶段，或用户明确授权额外审核时，才获得新的审核资格。

## Plan 审查

启用、身份、权限、等待和 thread 生命周期遵循主 Skill 的“Plan 双通道审查”。审查者使用 `plan_reviewer_agent_id`、Plan 审查角色、`read` 权限和独立新 thread；只检查 `PLAN_DRAFT` 的遗漏、偏移、错误假设、矛盾、工具权限、时序、审批门和验证缺口，不做业务研究、生产查询、写入、变更或下级委派。

输出 `PLAN_OK / PLAN_NEEDS_REVISION`。

## 验证门禁

待验证产出进入 `VALIDATING`：

- 无重要问题：建议 `ACCEPTED`，由主代理裁决。
- 有重要问题：进入 `NEEDS_REVISION`，附 `COMMUNICATION_EVENT`；主代理先报告问题、影响与返修方案。范围内且路线唯一时报告后继续，否则请求决定或重新审批。审核者关闭 thread，后续返修、确定性检查与最终验收由主代理接管，不再复核。
- 材料不足或工具受限：保持未接受，以 `BLOCKED` 回传影响和恢复条件。
- 平台故障：主代理说明“产出已生成，验证未闭环”，保存续跑入口。

验证者只接收原始目标、已批准 Plan 与验收标准、实际产出、原始证据、断言清单、构建入口和重跑标准；执行者自检标为待核实。

## 最终回复屏障

1. 进入验证时发送 `STATUS_REPORT`，说明验证范围和下一验收点；不得开始用户可见的最终正文。
2. 等待后台自动返回，不连续轮询；当前工作结束而后台仍运行时发送简短状态。
3. 结果返回后先裁决 `ACCEPTED / NEEDS_REVISION`，并将该阶段记为 `AUDIT_DONE`。
4. `NEEDS_REVISION` 先报告，再由主代理接管返修和验收；不得再次派审核助手或进行增量复核，是否等待由是否需要用户决定确定。
5. `ACCEPTED` 后一次性生成与 FINAL 对齐的最终回复。
6. 用户主动索要中间结果时，只提供显式标记的未验证草稿。

屏障只阻止最终正文，不得阻止阶段报告、事故通知、决策请求和重新审批。

## 验证规则

1. 检查真实文件、原始数据和确定性测试。
2. 关键数字和生成结果建立可复算断言，先证据后叙事。
3. 必要时独立查询只读数据，不只检查文本自洽。
4. 每个问题给出定位和证据。
5. 区分确定错误、风险、主观建议和无法验证项。
6. 验收标准自身矛盾时单独指出。
7. 不直接修复；每个阶段只运行一次审核，完成后立即关闭 thread，不与执行者往返。
8. 生成链必须固化；一次性命令或手工校正未进入构建链时不得建议接受。

## 结构化/MCP 工具受限

read 验证者看不到必要工具时，返回精确抽样清单并以 `BLOCKED` 结束本次审核。不得再创建独立数据验证执行者；主代理在自身权限范围内完成确定性核对，或请求 approver 决定。

## 跨会话审计

子代理不能跨会话。主代理使用宿主允许的跨会话工具读取目标会话，生成仅含可核查事件、文件路径和错误摘要的 `process_trace`；验证者读取轨迹与当前 Skill 审计，不可观察项标“无法确认”。轨迹不得包含完整私人上下文或凭证。

## 精简输出

```markdown
# 验证报告
## 建议状态
COMPLETED（建议 ACCEPTED） / NEEDS_REVISION / BLOCKED / FAILED / NEEDS_USER_DECISION
## 问题清单
| 严重程度 | 问题 | 证据或定位 | 影响 | 建议 |
## Plan 验收缺项
## 无法验证
## 建议动作
接受 / 一次定向修订 / 主代理接管 / 请求 approver 决定 / 重新审批
## 沟通事件
关键异常附 COMMUNICATION_EVENT；无则写“无”
```

验证报告不重复产出摘要。重要修订必须保存复核证据并确认构建链可重跑。
